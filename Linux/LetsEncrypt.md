Установка и автоматическое продление сертификатов Let's Encrypt
===============================================================

Установка `Certbot`
-------------------

    # если нет в репозитории
    sudo add-apt-repository ppa:certbot/certbot

    sudo apt install certbot


Дать права на каталоги и файлы сертификатов
-------------------------------------------

    sudo chmod -R 755 /etc/letsencrypt/{archive,live}


Установка сертификата на все поддомены `*.totalapi.io`
------------------------------------------------------

Требуется предварительно установленный `Ngnix`.

    sudo certbot certonly --nginx   --preferred-challenges dns   -d totalapi.io   -d *.totalapi.io




Просмотр текущих задач обновления сертификатов в `certbot`
----------------------------------------------------------

    sudo certbot certificates


Симуляция (!!!) процесса обновления для всех сертификатов, которые могут быть автоматически продлены
----------------------------------------------------------------------------------------------------

    sudo certbot renew --dry-run


Принудительное обновление
-------------------------

    sudo certbot renew --force-renewal


Удаление задачи автообновления сертификата
------------------------------------------

    sudo certbot delete --cert-name yourdomain.totalapi.io
